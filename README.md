# 算法研究平台 · 前端 V1

一个可公开共享的 React + Vite 前端。让用户上传图像、音频或视频，填写当前方法的专属参数，调用接入的水印 / 主动防御算法，预览并下载实际结果。

每个方法同时提供输入与输出样例，帮助使用者理解用途和目标效果。样例展示与用户任务的运行结果分开。

## 开始使用

建议使用 Node.js 22 或更新的 LTS 版本，在本目录执行：

```bash
npm install
npm run dev
```

终端会打印本地网页地址。构建静态前端：

```bash
npm run build
npm run preview
```

`npm test` 检查方法契约、参数、文件校验、音频处理和 HTTP 调用。样例文件已随源码附带，`npm run samples` 可以重新生成。无需在线图片、在线字体或 CDN。

## 页面

- **方法集合**：搜索并按图像 / 音频 / 视频、内容水印 / 主动防御筛选。
- **方法详情**：先展示各组的输入与输出样例，再上传自己的素材；每个参数独立显示输入框。
- **运行结果**：来自浏览器处理或该组 HTTP 算法服务，支持预览、文件下载、参数记录下载、清空本页。
- **接入算法**：可视化设置多素材输入、方法参数与样例，导入 / 导出方法 JSON，在当前浏览器登记预览。
- **接入指南**：统一请求与响应格式。

## 已附带的真实基础样例

1. 图像可见水印：浏览器 Canvas 绘制文字并导出 PNG。
2. 音频可听标记：浏览器解码音频，叠加周期提示音并导出 WAV。

两者只是基础流程样例，不声称实现论文级鲁棒水印、不可感知水印或防御效果。目录未放置虚假的待接入算法卡片；视频及真实论文方法由各组按接口接入。视频配置模板在 `public/templates/video_defense.json`。

## 接入一个方法

1. 让算法提供接收文件与参数的 HTTP 接口。CPU / GPU、Python 版本与环境由各组算法服务自行管理，前端无需迁移这些环境。
2. 在接入页定义字段、参数和样例，导出 `你的方法ID.json`。
3. 放入 `public/methods/`，在 `public/methods/index.json` 数组中增加该文件名。
4. 把样例文件放入 `public/samples/你的方法ID/`，填写对应相对路径。请只提交拥有公开展示权限的样例。
5. 提交到 GitHub 并发起 Pull Request。审核合并后，其他人拉取即可使用。

网页中的“登记到本机预览”**只写本机 localStorage，不会自动修改 GitHub 仓库**。共享方法必须提交配置和样例源码。刷新后本机登记仍在，方法页可确认后移除；它不会删除远端算法服务文件。

## 架构与边界

```text
React 页面 ← 方法 JSON：素材、参数、样例、接口
    ↓
动态素材 / 参数表单 → service 适配层
                       ├─ 浏览器基础样例 → Blob 文件
                       └─ HTTP 算法服务 → 真实结果文件 URL
                                             ↓
                               图像 / 音频 / 视频 / 文本 / JSON 展示
```

前端代码发布到 GitHub；GitHub 源码仓库本身不会运行 Python / CUDA 模型，也不会自动变成在线网页。可本地启动前端，或以后把 `dist/` 放到任意静态站点。

所有方法使用同一前端地址下的 `#/methods/方法ID`，不需要每个方法注册域名。哈希路由支持仓库子路径，刷新详情不会请求不存在的服务器子路由。算法服务可以集中或分别部署，其端口 / 环境不改变统一的前端入口。

当前 HTTP 契约采用单次请求；不含服务端任务队列、登录、多人权限、后端文件删除或环境自动安装器。长时间 GPU 方法后续可扩展异步任务协议。用户取消等待只中断前端请求。

## 文件与公开范围

```text
public/methods/      每个算法一份配置与目录索引
public/samples/      允许公开的输入输出样例
public/templates/    视频防御配置模板
src/components/      素材预览、动态参数、运行工作区
src/pages/           集合、详情、接入与指南
src/services/        浏览器处理与 HTTP 适配
src/lib/             契约校验、目录读取、本机登记
docs/                使用、接入、GitHub 共享说明
tests/               关键契约与处理测试
```

只把这个独立目录作为 GitHub 仓库根目录。不要上传父目录中的旧系统、NAS 配置、模型权重、环境压缩包、录音照片、服务器地址或凭据。`.gitignore` 已排除依赖、构建输出、环境变量和常见运行文件。
