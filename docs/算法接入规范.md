# 算法接入规范

接入一个方法需要准备三项内容：接收素材与参数的 HTTP 接口、一份方法 JSON 配置、至少一组输入与输出样例。可参考 [视频防御配置模板](../public/templates/video_defense.json)。

## 1. 方法配置

| 字段 | 要求 |
| --- | --- |
| `schema_version` | 固定为 `"1.0"`。 |
| `id` | 全局唯一；小写字母开头，仅含小写字母、数字和下划线，长度 2–64。 |
| `title`、`summary`、`description` | 方法名称、用途简介、详细说明，均必填。详细说明中写明论文信息、适用范围和效果限制。 |
| `team`、`version` | 贡献团队与方法版本，均必填。 |
| `category` | `内容水印` 或 `主动防御`。 |
| `english`、`runtime` | 可选的英文名称与运行设备说明。 |
| `inputs` | 1–8 个素材字段。 |
| `parameters` | 0–40 个额外参数。无参数时使用空数组。 |
| `examples` | 1–12 组输入与输出样例。 |
| `adapter` | HTTP 调用配置。 |

输入和参数的 `name` 遵循与方法 ID 相同的命名规则，且在方法内不可重复。请避开请求保留字段 `method_id` 和 `parameters`。

## 2. 素材输入

每个素材字段代表一个文件，可组合图像 `image`、音频 `audio`、视频 `video`，例如一张人像和一段语音。

```json
{
  "name": "input_file",
  "label": "原始视频",
  "kind": "video",
  "accept": ["video/mp4"],
  "required": true,
  "max_mb": 100
}
```

`accept` 为 MIME 类型列表，须与 `kind` 对应，例如 `image/png`、`audio/wav`、`video/mp4`，也支持 `image/*` 等通配格式。`max_mb` 必须大于 0 且不超过 500，应按实际算法能力设置。

前端按配置验证文件格式和大小；算法服务仍需校验实际文件内容、解码能力和资源需求。

## 3. 额外参数

每个参数自动对应一个独立输入控件：

| `type` | 控件与值类型 |
| --- | --- |
| `text` | 单行文字，字符串。 |
| `textarea` | 多行文字，字符串。 |
| `number` | 数值输入，JSON 数字。 |
| `integer` | 整数输入，JSON 整数。 |
| `select` | 下拉选项，使用选项的字符串 `value`。 |
| `boolean` | 开关，JSON 布尔值。 |

每项填写 `name`、`label` 和 `type`，可设置 `required`、`default`、`help`。数字参数支持 `min`、`max`、`step`；文字参数支持 `max_length`，未设置时按 2000 字符校验；下拉参数需提供非空的 `options: [{"value":"...","label":"..."}]`。

```json
{
  "name": "strength",
  "label": "保护强度",
  "type": "number",
  "default": 0.05,
  "min": 0,
  "max": 1,
  "step": 0.01,
  "required": true,
  "help": "值越大，保护扰动越强。"
}
```

参数说明和取值范围应与实际算法一致。可选参数留空时不会写入请求的参数对象。

## 4. 算法请求

配置完整的 HTTP(S) 地址：

```json
{
  "type": "http",
  "endpoint": "https://your_algorithm.example/process"
}
```

将以上对象放入方法配置的 `adapter` 字段。前端向该地址发送 `POST multipart/form-data`：

| 请求字段 | 类型 | 内容 |
| --- | --- | --- |
| 素材字段的 `name` | 文件 | 每个已选择的素材独立发送，字段名与配置一致，保留上传文件名。 |
| `method_id` | 字符串 | 方法 ID。 |
| `parameters` | JSON 字符串 | 例如 `{"strength":0.05,"seed":42,"repeat":false}`。 |

服务端需将 `parameters` 解析为 JSON 对象，按方法要求再次校验。上传文件名应作为元数据处理，避免直接拼接执行命令。

当前调用在同一请求中等待结果；接口应在处理完成后返回结果 JSON。前端暂不识别返回任务 ID 后轮询的异步协议。CPU / GPU、依赖环境、并发与资源配额由算法服务负责。

浏览器请求不自动携带 Cookie 或访问密钥。接口和结果文件需允许前端来源跨域访问；HTTPS 页面使用 HTTPS 接口与资源。公开配置中不得包含服务凭据。

## 5. 算法响应

成功时返回 HTTP 200 和 JSON，例如：

```json
{
  "message": "防御处理完成",
  "artifacts": [
    {
      "kind": "video",
      "label": "保护后视频",
      "filename": "protected.mp4",
      "url": "https://your_algorithm.example/files/protected.mp4"
    },
    {
      "kind": "json",
      "label": "水印溯源报告",
      "filename": "report.json",
      "url": "https://your_algorithm.example/files/report.json"
    }
  ]
}
```

`artifacts` 包含 1–20 个结果。`kind` 支持 `image`、`audio`、`video`、`json`、`text`：媒体结果提供预览或播放，JSON 与文本报告提供文件入口和下载。允许只返回报告，也允许返回多个不同类型的结果。

每个结果填写 `kind`、`url`，并建议填写便于识别的 `label` 与 `filename`。`url` 使用 HTTP(S) 地址或相对地址；相对地址按接口 URL 解析，而非按前端地址解析。返回地址应指向可读取的结果文件，且允许跨域下载，不能使用服务器磁盘路径。视频建议 MP4（H.264 / AAC），音频建议 WAV / MP3。

失败时返回适当的非成功 HTTP 状态码，并提供 `{"error":"用户可理解的错误说明"}`。结果须来自本次输入的实际处理，样例仅用于方法展示。

用户取消等待会中断前端请求；服务端任务是否随之停止、文件保留多久以及如何清理，应由算法服务实现并在方法说明中写明。

## 6. 效果样例

每组样例包含标题、观察重点、输入和对应的实际输出：

```json
{
  "title": "短视频保护示例",
  "description": "对比保护前后画面，并说明该方法的目标效果。",
  "input": {
    "src": "samples/my_video_defense/input.mp4",
    "kind": "video",
    "label": "原始视频"
  },
  "output": {
    "src": "samples/my_video_defense/output.mp4",
    "kind": "video",
    "label": "保护后视频"
  },
  "parameters": { "strength": 0.05, "seed": 42 }
}
```

样例 `kind` 支持图像、音频和视频。报告类输出可用实际报告截图展示效果，运行结果仍可返回 JSON 或文本文件。

相对 `src` 从前端站点根目录解析，填写 `samples/方法ID/文件名`，不带 `public/` 前缀；也可填写可访问的 HTTPS 地址。建议提供产生样例的参数，单素材方法可通过“用样例试一试”载入。多素材方法需手动选择各文件，并在描述中说明输入组合。

样例素材须具有公开展示权限，建议每个方法的样例总量不超过 20 MB。完成配置后，按[算法提交指南](算法提交指南.md)共享方法，并逐项完成[接入自查清单](接入自查清单.md)。
