# 接入自查清单

在提交方法或更新接口前完成以下检查。

## 方法信息与配置

- [ ] 方法 ID 唯一，配置文件名与索引条目一致。
- [ ] 名称、团队、版本、用途、论文信息和适用范围填写完整。
- [ ] 每个素材字段的类型、格式、大小限制和必填状态符合算法要求。
- [ ] 每个额外参数的名称、类型、默认值、范围及说明与接口一致。
- [ ] 配置不包含服务凭据，样例具有公开展示权限。

## 样例与页面

- [ ] 至少一组输入、输出样例可访问，输出确实由对应输入产生。
- [ ] 样例说明写明观察重点、使用参数和必要的输入组合。
- [ ] 方法能在集合中找到，详情页面刷新后可正常显示。
- [ ] 文件可以重新选择、移除；缺少素材和参数越界时有明确提示。
- [ ] 在常用屏幕尺寸下，参数输入、媒体播放和按钮可正常使用。

## 算法接口与结果

- [ ] 使用自己的文件完成过一次真实处理，并检查全部参数是否传入。
- [ ] 接口正确解析 multipart 文件与 `parameters` JSON 字符串。
- [ ] 响应包含 1–20 个有效结果，类型与实际文件相符。
- [ ] 结果地址可在浏览器访问，预览和下载正常，跨域设置完整。
- [ ] 服务不可用、文件无法解码或参数无效时返回可理解的错误。
- [ ] 已说明耗时或资源限制、取消请求后的行为以及文件清理方式。

## 提交文件

- [ ] 已提交方法 JSON、索引变更及所需样例。
- [ ] 未夹带用户任务文件、依赖环境、模型权重或服务密钥。
- [ ] `npm test` 与 `npm run build` 通过。
- [ ] Pull Request 写明验证方式、接口状态和已知限制。
