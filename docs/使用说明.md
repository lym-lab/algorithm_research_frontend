# 算法研究平台前端 V1 使用说明

更新日期：2026 年 10 月 12 日。此版取代此前以服务器任务管理为重点的前端方向，旧 V0.7 保留为历史版本。

## 平台做什么

统一体验各组的内容水印与主动防御算法：**查看样例 → 上传自己的图片 / 音频 / 视频 → 填写当前方法专属参数 → 处理 → 查看与下载结果**。与课程评分无关。

## 普通使用者

1. 打开本地启动后的前端，进入“方法集合”。可按素材类型、方法分类筛选，或搜索方法名称和团队。
2. 进入方法详情，观察成对的输入、输出样例和效果说明。
3. 在下方“输入素材”选择文件。上传格式和大小由该方法规定，可重新选择或移除；也可用方法提供的样例试跑。
4. 在“方法参数”逐个填写额外参数。例如水印文字、保护强度、目标模型或随机种子。必填、范围和类型会在运行前校验。
5. 点击“开始处理”。浏览器基础样例本地执行；其他方法会把素材与参数发送到该组配置的 HTTP 接口。
6. 完成后预览图像、播放音频 / 视频、打开结构化报告，下载结果及本次参数记录。
7. 点击“清空本页”释放本页文件与结果引用。切换页面或刷新也会释放本页运行数据。

**文件在哪里？** 浏览器样例文件只保留在内存，除非主动下载，不会写入 NAS。HTTP 方法上传到其自己的算法服务，其存储和清理规则由该组决定；前端清空不等同于远端删除。

## 算法贡献者

在“接入算法”页面填写方法信息、HTTP 接口、素材输入、参数及样例。每个参数单独增加一行，支持单行文字、多行文字、小数、整数、下拉选项和开关。

每组至少提供一组**同一输入对应的实际输出**和效果解释。样例不是用户运行结果的替代品。导出 JSON 后，把配置与可公开的样例文件提交到同一个 GitHub 仓库即可。

“登记到本机预览”方便测试接口与页面，但只有当前浏览器能看到。其他人需要拉取合并后的 GitHub 源码。移除本机登记需要确认，只影响该浏览器配置；删除已共享方法需通过仓库变更。

## CPU / GPU、环境与平台位置

CPU / GPU 算法均可接入，前提是算法服务提供约定的 HTTP 接口。平台前端不加载 Python / CUDA，不把不同方法的依赖装到同一环境，因此各组环境不会在前端互相冲突。多 GPU 并发、队列、内存配额由算法运行侧管理，不能仅靠网页解决。

当前交付是可公开拉取的前端源码，**不依赖华为云，不要求部署到实验室服务器**。GitHub 源码公开和网页在线托管是两件事。拉取后 `npm install`、`npm run dev` 即可打开；真实算法仍需各组提供可访问服务。

各方法位于同一网页的 `#/methods/方法ID`。后续只有一个前端站点域名即可，不为每组方法单独申请域名。

## 当前范围

- 已有两个真实运行的基础样例：图像可见文字水印、音频可听周期标记。
- 视频上传、播放、参数传递、HTTP 结果展示由同一套组件支持；真实视频防御需要接入真实接口。模板不作为已实现算法展示。
- 不把固定结果冒充实时计算，不声称基础样例实现论文防御能力。
- 无登录、评分、自动安装环境、服务端任务队列。前端无法自行启动各组模型或清理算法服务器文件。

## 常见情况

**接口连接失败：** 检查服务是否启动、地址是否可达、是否允许当前前端来源跨域访问。HTTPS 网页不要调用 HTTP 接口。

**素材无法播放：** 检查返回的文件 URL，视频建议 MP4（H.264 / AAC），音频建议 WAV / MP3；不要返回 `/home/...` 等服务器本地路径。

**取消后 GPU 还在运行：** 当前取消仅中止浏览器等待，需要服务端实现任务取消才可停止计算。

**仓库中的样例不能公开：** 更换获准公开的样例，不要把现场录音、照片或内部实验数据提交到公开仓库。
