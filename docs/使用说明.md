# 使用说明

平台提供内容水印与主动防御方法的样例展示、素材处理和结果下载。每个方法有自己的素材要求和参数，请以当前方法页面的说明为准。

## 选择方法

打开平台后，在“方法集合”中按名称、团队或关键词搜索，也可按图像、音频、视频和方法分类筛选。进入方法详情，阅读用途、适用范围以及输入、输出样例。

内置的图像可见水印和音频可听标记是基础体验方法：前者给图像添加文字，后者给音频叠加周期提示音。

## 上传素材并处理

1. 在“输入素材”选择文件。每个输入框显示支持的格式和大小限制，带星号的字段为必填项。
2. 如需更换文件，点击素材区域重新选择；点击“移除此素材”可取消选择。
3. 在“方法参数”中填写该方法需要的内容，例如水印文字、保护强度、随机种子或目标选项。没有额外参数的方法可直接运行。
4. 点击“开始处理”。缺少素材或参数不符合要求时，按页面提示修改后重试。
5. 等待处理完成。耗时与素材大小、算法和运行设备有关。

“用样例试一试”会载入当前样例的输入和已配置的参数，适用于单素材方法。多素材方法需要分别选择各输入文件。

浏览器基础方法在本机处理素材。HTTP 方法在点击“开始处理”后将素材和参数发送给该方法的算法服务。

## 查看与保存结果

图像、音频和视频可在结果区域预览或播放；文本与 JSON 报告提供文件入口。一个方法可能返回多个文件，例如保护后视频和分析报告。

点击“下载结果”保存对应文件；点击“下载参数记录”保存方法 ID、版本、输入文件名与本次参数，便于复现同一次处理。

建议在离开页面前下载需要保留的结果。切换方法或刷新页面会清除当前页面的素材和结果状态。

## 取消与清空

- **取消等待**：中断当前浏览器请求。算法服务是否停止计算取决于该服务的实现。
- **清空本页**：移除本页素材和结果，并恢复参数默认值。该操作不删除已下载文件，也不删除算法服务保存的文件。

算法服务上的文件保存时间和清理方式，请查看该方法的说明或联系其提供者。

## 常见问题

| 情况 | 处理方法 |
| --- | --- |
| 文件格式或大小不符合要求 | 按输入框标注转换格式或缩小素材后重试。 |
| 参数提示无效 | 检查必填项、数字范围和整数要求。 |
| 无法连接算法接口 | 确认网络可用；若持续失败，联系方法提供者检查服务状态。 |
| 结果无法播放或下载 | 尝试打开结果文件入口；若仍失败，联系方法提供者检查格式、文件地址和下载权限。 |
| “用样例试一试”加载失败 | 多输入方法请手动选择素材；样例文件无法访问时，联系方法提供者。 |
| 本机登记的方法在其他设备看不到 | 本机登记仅保存在当前浏览器。共享方法需按[算法提交指南](算法提交指南.md)提交。 |

需要接入自己的算法，请阅读[算法接入规范](算法接入规范.md)。
